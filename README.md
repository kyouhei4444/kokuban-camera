# 黒板カメラ

### ▶ 公開URL： https://kyouhei4444.github.io/kokuban-camera/

スマホの Chrome（iPhone は Safari）で開き、「ホーム画面に追加」するとアプリとして使えます。

電子小黒板を焼き込んだ工事写真を、**4:3（標準 1280×960）**で撮るスマホ用カメラ。
`_apps/doryo-scan` などと同じ **PWA（ブラウザアプリ）**。HTTPS で開いて「ホーム画面に追加」すると、アプリとして全画面で動き、オフラインでも撮影できる。

## できること

| 機能 | 内容 |
|------|------|
| 現場の登録・選択 | ホームで工事名・受注者名を登録。最後に使った現場が上に来る |
| 黒板の入力 | 工種・種別・測点・黒板内容。入力履歴をチップ／候補で再利用。測点は ◀▶ で No.5→No.6 |
| 表形式 | 黒板内容に `項目\|設計\|実測` と書くと表になる |
| 画素数 | 640×480／**1280×960（既定）**／1600×1200／2048×1536／2592×1944（すべて 4:3） |
| 向き | 自動（スマホの向き）／いつも横／いつも縦 |
| 黒板 | 指でドラッグして配置、＋−で大きさ。緑・黒・白。載せる項目と日付の書き方（和暦・西暦）を選べる |
| Exif | 撮影日時（DateTimeOriginal）・画素数・任意で GPS を JPEG に書き込む（電子納品ソフトで撮影日が読める） |
| 写真一覧 | 共有・保存・削除。**ZIP（撮影台帳 CSV 付き）**で一括書き出し |
| SHA-256 | 撮影直後の画像の SHA-256 を記録し、撮影台帳に載せる |
| その他 | ライト（対応機種）、ズーム（対応機種）、静止画モード（ImageCapture 対応機種）、画面の消灯防止 |

## 電子納品での注意

画像に黒板を**焼き込む**方式。デジタル写真管理情報基準でいう「小黒板情報の電子化」として扱うには
**J-COMSIA の信憑性確認（改ざん検知機能）対応ソフト**であることが条件で、本アプリは認定を受けていない。
電子小黒板として使う場合は**事前に監督員と協議**すること。

## ファイル

```
index.html / css/style.css / manifest.webmanifest / sw.js / icons/
js/exif.js    Exif（APP1）の組み立てと差し込み
js/zip.js     無圧縮 ZIP（UTF-8 ファイル名）
js/board.js   黒板の描画（プレビューと保存画像で共通）
js/store.js   現場・設定（localStorage）、写真（IndexedDB）
js/camera.js  カメラ映像の取得と 4:3 切り出し
js/app.js     画面の動き
test/         通しテスト（python test/run_test.py。偽カメラのヘッドレス Chrome で撮影→Exif/ZIP を検証）
```

## 公開（HTTPS が必要）

カメラはブラウザの決まりで HTTPS からしか使えない。GitHub Pages に置く場合は doryo-scan と同じ手順
（リポジトリを作って push → Settings → Pages → main / root）。
更新を反映するときは `sw.js` の `APP_CACHE` の版数を上げる。
